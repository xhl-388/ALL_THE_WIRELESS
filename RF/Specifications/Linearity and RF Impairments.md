# 线性度与射频失真

真实放大器、混频器等电路并非理想线性器件。大信号可能压缩增益；多个信号同时输入时，非线性还会生成落入目标信道的互调产物。排查时要区分**信号过强导致的非线性**与**噪声、频率误差或外部干扰**。

## 压缩与互调

- **$P_{1\mathrm{dB}}$（1 dB 压缩点）**：实际增益相对小信号线性外推值下降 1 dB 时的输入功率（IIP1dB）或输出功率（OIP1dB）。它标记开始明显压缩的区域，不是最大安全输入或饱和功率。
- **IMD（互调失真）**：非线性器件同时接收多个频率时产生的新频率。对间隔较近的双音 $f_1,f_2$，三阶项包括 $2f_1-f_2$ 和 $2f_2-f_1$；它们可能落在原信号附近，难以靠滤波去除。
- **IIP3/OIP3（三阶截点）**：把小信号区基波和三阶互调随输入功率变化的直线外推，其交点是一个**虚拟指标**，器件不会真的在线性状态下工作到该功率。双音测试、每音功率为 $P_{in}$ 时，若基波与 IM3 的差为 $\Delta=P_{fund,out}-P_{IM3,out}$，则

  $$
  OIP3=P_{fund,out}+\frac{\Delta}{2},\qquad IIP3=P_{in}+\frac{\Delta}{2}
  $$

  输入/输出截点相差小信号增益。一般同条件下截点越高表示线性度越好；**IIP3 不是 P1dB 的固定换算值**，比较时必须同时看频率、双音间隔、功率及测试条件。
- **Blocker（阻塞干扰）**：目标信号之外的强干扰可能使接收机前端压缩、产生互调、通过本振相位噪声发生 reciprocal mixing，或令 AGC 降低增益，最终造成灵敏度恶化（desense）。

双音 $f_1<f_2$ 经过非线性器件后，三阶互调会靠近原信号，常规带通滤波器很难把它们完全滤掉：

```text
功率
  ↑       IM3      基波       基波      IM3
  │       │         │          │         │
  └───────┼─────────┼──────────┼─────────┼────→ 频率
       2f₁−f₂       f₁         f₂      2f₂−f₁
```

## 相位噪声、延迟与其他失真

- **相位噪声**：振荡器相位的随机变化表现为载波两侧的噪声裙边；常以相对载波的单边带 $L(\Delta f)$（dBc/Hz）对偏移频率 $\Delta f$ 描述。接收机中，强邻近阻塞信号可与 LO 相位噪声混频，将能量搬入目标 IF/信道；发射机中则可能增加邻道/带外能量。不要把某个偏移处的 dBc/Hz 直接当作总相位抖动。
- **载波频率偏移（CFO, carrier frequency offset）**：发射端载波与接收端本地振荡器的频率基准不一致，使接收信号相对接收机参考频率偏移 $\Delta f$。常见来源是两端参考晶振/PLL 的误差及温漂；相对运动造成的多普勒频移也会贡献频偏。对应的相位随时间累积变化，$\Delta\phi(t)=2\pi\Delta f t$。在 OFDM 中，CFO 会令星座持续旋转并破坏子载波正交性，造成子载波间干扰（ICI）；接收机通常用前导训练序列和导频估计并校正。CFO 是相对频率基准的偏差，不等同于相位噪声的随机抖动；参见 [[OFDM]]。
- **I/Q 不平衡（IQ imbalance）**：理想 I、Q 两路应有相同增益，且相位差为 $90^\circ$。实际的增益不匹配或正交相位误差会使星座图变形，并造成镜像频率泄漏、EVM 恶化；发射端可能产生镜像杂散，接收端则可能受到镜像信号干扰。收发机可通过校准或数字补偿减轻影响。共同的整体相位旋转本身不等于 I/Q 不平衡；直流偏置和 LO 泄漏是相关但不同的误差。
- **群时延（group delay）**：$\tau_g=-d\phi/d\omega$，描述不同频率分量包络的延迟。带内群时延不平坦会改变宽带调制信号的波形，造成码间干扰；恒定延迟本身只是整体平移，不会造成这种波形失真。
- **相位延迟（phase delay）**：在常用相位约定下 $\tau_p=-\phi/\omega$。相位的正负取决于传递函数约定；不要把相位除以频率而忽略符号及角频率单位。
- **DPD（数字预失真）**：通过观察/建模 PA 的非线性，在数字基带预先施加近似反向的非线性，使 PA 输出更接近目标波形。可改善发射 EVM 与邻道泄漏，但效果受带宽、模型、反馈链路及 PA 工作点限制。
- **PAE（功率附加效率）**：$PAE=(P_{RF,out}-P_{RF,in})/P_{DC}\times100\%$。它与只用 $P_{RF,out}/P_{DC}$ 的漏极/集电极效率不同；比较时确认输入、输出和直流功率的测量参考面。
- **Feedthrough（馈通）**：例如 LO 泄漏到 RF 或 IF 端口，可能成为杂散发射；在零中频架构，LO 泄漏自混频还可能形成直流偏置。参见 [[Image Rejection Mixer]] 和 [[PLL]]。
- **Pulling（牵引）**：振荡器频率/相位因负载阻抗变化而偏移。它与晶体负载电容、振荡器输出负载及缓冲隔离有关；不要与温度漂移或参考晶体频率误差混为一谈。
- **Frequency kicking（频率踢动）**：PA 开关或发射功率突变经供电、地线或寄生耦合扰动参考振荡器/LO，形成短时频率或相位扰动。缓和 PA 边沿、改善电源去耦/布局及隔离可帮助降低此问题。
- **预加重/去加重、包络整形**：发送端有意调整频率响应或开关边沿，接收端按约定恢复/检测。整形常用于减少带外频谱，但不能不考虑噪声、带宽和接收端实现。
