**BPSK（Binary Phase Shift Keying，二进制相移键控）是用载波的两种相位状态表示 0 和 1。**你可以把它看成：频率保持在同一个标称值附近，但把波形按需要“翻个面”。

沿用 433.920 MHz 的例子，先看一个简化约定：

```text
发送 0：cos(2πft)
发送 1：−cos(2πft)
```

其中 `f = 433.920 MHz`。因为 `−cos(2πft) = cos(2πft + π)`，所以第二种波形相当于**相位比第一种差 180°**。

直观地说，原来波形处于波峰的位置，翻转后就处于波谷：

```text
0：  +  −  +  −  +  −
1：  −  +  −  +  −  +
```

这里的 `+ −` 只是示意波形的正负，不是数字比特。

### 它和 FSK 有什么不同？

| 调制方式 | 用什么区别 0 和 1？ |
|---|---|
| 2-FSK | 两个**频率档位**，例如 433.915 和 433.925 MHz |
| BPSK | 两个**相位状态**，相差 180°，标称载波频率相同 |

如果连续发送 `000`，理想 BPSK 波形在这几个符号之间不需要翻转；如果发送 `010`，在 `0→1` 和 `1→0` 的边界各翻转一次。**不是载波每振荡一圈就翻转一次**：载波仍以约 433 MHz 振荡，数据只决定什么时候改变它的相位状态。

### 接收端怎么知道有没有“翻面”？

接收端产生一个与发射载波**频率、时序和相位对准**的参考波，把收到的信号与它比较：

- 同相，比较结果倾向于正值；
- 相差 180°，比较结果倾向于负值。

然后在一个符号时间内累加，再判为 0 或 1。这也是 BPSK 接收需要解决**载波同步**的原因：如果参考波的相位没对准，接收端不能仅凭一次正负比较可靠地认出比特。

### 放回 DSSS 的例子

我们之前说：**1 个数据比特 → 8 个码片**，每个码片持续 12.5 微秒。若使用 **DSSS + BPSK**，就是让这 8 个码片依次控制载波处于“原样”还是“翻面”的状态。接收端先识别并对齐扩频码，再把码片的信息合起来判断原来的那个数据比特。

最后联系你刚理解的傅里叶变换：**“BPSK 只有两种相位”也不等于“频谱只有一根线”。**相位状态随码片切换，整段波形会随时间变化；切换得多快、如何平滑切换，都会影响频谱。
