LC 振荡可以先非常直观地理解成：

> **电容 C 和电感 L 之间，能量来回倒腾，形成周期性的电压、电流变化。**

LC 里的：

- **L = Inductor，电感**

- **C = Capacitor，电容**

---

## 1. 先用一个“水箱”类比

把电容想象成一个**装水的水箱**：

```text
       水
   ┌────────┐
   │████████│
   │████████│
   └────┬───┘
        │
        ▼
      管道
```

电容充电之后，相当于“储存了能量”。

电感则有点像一个具有**惯性的大水轮**。

所以把 C 和 L 接起来：

```text
      C                 L
   ┌──────┐          ┌──────┐
   │      │──────────│      │
   │  C   │          │  L   │
   │      │──────────│      │
   └──────┘          └──────┘
```

能量会在 C 和 L 之间来回交换。

---

# 2. 第一个瞬间：能量全部在电容里

假设我们先给电容充电：

```text
       + + + + +
     ┌──────────┐
     │    C     │
     └──────────┘
       - - - - -
```

此时：

$$
E_C=\frac12CV^2
$$

电容有电压，但是电路中：

$$
I=0
$$

也就是说：

> **能量主要存在电容的电场里。**

---

# 3. 然后电容开始放电

把它和电感接起来。

电容开始放电：

```text
        电流 →
     ┌──────────┐
     │    C     │
     └──────────┘
          │
          ▼
       ┌─────┐
       │  L  │
       └─────┘
```

电流开始增大。

但是电感有一个非常重要的特性：

$$
V_L=L\frac{dI}{dt}
$$

它会**阻碍电流的快速变化**。

所以电流不会瞬间变成无限大。

---

# 4. 到某个瞬间：电容完全放完

假设刚好到了：

```text
C 电压：

开始       中间        现在
██████      ███         0
```

此时：

$$
V_C=0
$$

但这时候电流反而最大：

```text
I = 最大
```

因为刚才电容释放的能量已经转移到了电感：

$$
E_L=\frac12LI^2
$$

所以出现了一个非常有意思的情况：

```text
开始：

C：████████████
L：


后来：

C：
L：████████████
```

**能量从电容跑到了电感。**

---

# 5. 但是事情还没结束

因为电感有“惯性”。

即使电容已经放完了，电感中的电流仍然不会立刻停止。

所以电流继续流：

```text
        →
     ┌──────┐
     │  C   │
     └──────┘
        ↑
        │
     ┌──────┐
     │  L   │
     └──────┘
```

结果：

> 电感又把电容反方向充电了。

于是：

```text
第一次：

C +++++
C -----

      ↓ 放电

L █████


第二次：

C -----
C +++++

      ↓ 放电

L █████
```

电容的极性反过来了。

---

# 6. 然后再来一次

电容又开始反方向放电：

```text
C
↓
L
↓
C
↓
L
↓
C
↓
...
```

所以能量一直来回交换：

```text
       电能
      C
     ↙ ↘
    ↙   ↘
   ↙     ↘
  L ←─────
     磁能
```

这就是：

# LC 振荡

---

# 7. 为什么叫“振荡”？

因为电压和电流会不断变化：

$$
V_C(t)=V_0\cos(\omega t) \qquad I(t)=I_0\sin(\omega t)
$$

你可以想象成：

```text
电压

  +V
   │    /\        /\
   │   /  \      /  \
  0│──/────\────/────\──→ t
   │ /      \  /
   │/        \/
  -V
```

电流则和它错开 90°：

```text
电流

  +I
   │      /\        /\
   │     /  \      /  \
  0│────/────\────/────\──→ t
   │   /      \  /
   │  /        \/
  -I
```

所以叫 **oscillation（振荡）**。

---

# 8. LC 振荡频率是多少？

非常重要的公式：

$$
\boxed{f_0=\frac{1}{2\pi\sqrt{LC}}}
$$

或者：

$$
\boxed{\omega_0=\frac{1}{\sqrt{LC}}}
$$

这里：

- $L$：电感，单位 H

- $C$：电容，单位 F

- $f_0$：振荡频率，单位 Hz

例如：

$$
L=1\,\mu\text{H}, \qquad C=100\,\text{pF}
$$

那么：

$$
f_0 = \frac{1}{2\pi\sqrt{10^{-6}\times10^{-10}}}
$$

大约：

$$
\boxed{15.9\text{ MHz}}
$$

这已经是典型的 **RF 频率**了。

---

# 9. 这就和刚才的 Spark-gap transmitter 连起来了

刚才我们说：

```text
高压电源
   ↓
给电容充电
   ↓
电压越来越高
   ↓
Spark gap 击穿
   ↓
C 突然连接到 L
   ↓
LC 振荡
   ↓
高频电流
   ↓
天线
   ↓
无线电波
```

所以 **spark gap 本身并不是产生 RF 频率的核心**。

真正决定振荡频率的是：

$$
\boxed{L\ \text{和}\ C}
$$

而 spark gap 更像一个：

> **“咔嚓一下，把已经充好电的 C 和 L 接起来”的开关。**

---

## 10. 但现实中的 LC 振荡不会永远振

这是非常重要的一点。

实际电路存在电阻：

```text
       R
       │
C ─────L─────
```

所以每次能量交换都会损失一点。

结果变成：

```text
     /\ 
    /  \      /\
   /    \    /  \
__/      \__/    \____
```

这种叫：

> **damped oscillation（阻尼振荡）**

而 Spark-gap transmitter 恰恰就是利用这种**阻尼 LC 振荡**来产生无线电波。

所以如果你接下来想理解 **“为什么一个 LC 振荡电路接上天线以后，就能把能量真正辐射成电磁波”**，那下一步其实就是理解 **天线为什么会辐射**。这一步会把 LC 电路和你前面问的 Maxwell 方程真正连起来。
