**Spark-gap transmitter（火花隙发射机）**是一种非常早期的无线电发射机，大约在 19 世纪末到 20 世纪初使用得非常广泛。它的核心思想其实非常直观：

> **先把电能存起来 → 突然让空气被击穿 → 产生火花 → 形成高频振荡电流 → 向天线辐射无线电波。**

之所以叫 **spark-gap transmitter**，就是因为它里面有一个非常关键的部件叫 **spark gap（火花隙）**。

### 1. Spark gap 是什么？

想象两个金属球：

```text
     金属球             金属球
       ●                   ●
       │                   │
       │ ←── 空气间隙 ──→ │
       │                   │
```

两个金属球之间故意留一个很小的空气间隙。

正常情况下：

```text
●      空气      ●
```

空气基本上是绝缘体，所以电流过不去。

但是如果两边电压越来越高，达到某个程度之后，空气会发生**电击穿**：

```text
●  ⚡⚡⚡⚡⚡  ●
```

空气被电离，突然变成了导体，于是产生一个非常短暂但很强的**火花放电**。

这就是：

> **spark gap = 火花隙**

---

## 2. 它为什么能发射无线电波？

一个经典的 spark-gap transmitter 大致可以画成：

```text
        高压电源
           │
           │
      ┌────┴────┐
      │         │
      │        电容 C
      │         │
      │         │
      └───┬─────┘
          │
      ●   │   ●
      ← spark gap →
          │
         L
       线圈
          │
       天线
          │
         GND
```

更准确一点，可以理解成 **LC 振荡器 + 火花开关**。

### 第一步：给电容充电

高压电源不断给电容充电：

```text
       + + + + +
     ┌──────────┐
     │    C     │
     └──────────┘
       - - - - -
```

电压越来越高。

例如：

```text
100 V
 ↓
1000 V
 ↓
5000 V
 ↓
10000 V
 ↓
💥 击穿
```

---

### 第二步：空气被击穿

达到 spark gap 的击穿电压之后：

```text
●       ●
 \     /
  \⚡/
   ↓
突然导通
```

注意这里非常重要：

**spark gap 本质上就像一个非常粗暴的高速开关。**

平时：

```text
OFF
```

电压达到一定程度：

```text
ON !!!
```

---

### 第三步：LC 开始振荡

电容里面已经存了能量：

$$
E_C=\frac12CV^2
$$

突然导通以后，电容通过线圈放电。

于是：

```text
电容
 ↓
线圈
 ↓
电容
 ↓
线圈
 ↓
...
```

形成 LC 振荡：

$$
f_0=\frac{1}{2\pi\sqrt{LC}}
$$

例如：

```text
      电流
       ↑
       │    /\
       │   /  \
       │__/    \__
       │          \__
       └──────────────→ t
```

也就是说，电路中突然出现了一个**高频振荡电流**。

---

## 4. 高频电流为什么能变成无线电波？

因为这个振荡电流连接到了天线。

例如：

```text
        高频电流
           ↑
           │
          ││
          ││   ← 天线
          ││
          ││
          ││
          ││
           │
          GND
```

天线里面的电流不断变化：

$$
I(t)=I_0\sin(2\pi ft)
$$

不断变化的电流会产生变化的电磁场。

根据你刚才问到的几个 Maxwell 方程：

- 变化的电场产生磁场

- 变化的磁场产生电场

于是电磁场可以脱离天线向空间传播。

这就是：

> **无线电波**

---

# 5. 为什么它叫 transmitter？

因为它的作用就是：

**transmit（发送）radio waves（无线电波）**

所以：

> **spark-gap transmitter = 火花隙无线电发射机**

这个名字其实是按照它最核心的技术来命名的：

```text
spark gap
   ↓
火花放电
   ↓
产生高频振荡
   ↓
天线
   ↓
电磁波
   ↓
无线通信
```

---

# 6. 这种发射机有一个非常大的缺点

它产生的并不是今天这种漂亮的：

$$
\boxed{f=10\text{ MHz}}
$$

的干净正弦波。

而更像：

```text
       一串衰减振荡
       ↓

    /\      /\      /\
   /  \    /  \    /  \
__/    \__/    \____    \__
↑
火花发生
```

每发生一次火花，就激发一次 **damped oscillation（阻尼振荡）**。

所以它实际上产生的是一大堆频率成分：

```text
频谱

     │
     │ █
     │ █ █
     │ █ █ █
─────┴──────────────→ f
       很宽
```

也就是说：

> **spark-gap transmitter 的频谱非常宽。**

这会造成严重的无线电干扰。

---

# 7. 这也是为什么后来被淘汰

早期无线电：

```text
Spark gap transmitter
        ↓
       📡
        ↓
       ~~~
   无线电波
```

虽然简单，但是它无法很好地控制频率。

后来出现了**连续波（CW）发射机**：

```text
        ─────────────────
       ~~~~~~~~~~~~~~~~~~~
        ─────────────────
```

可以稳定地产生：

$$
f = 1.000\,\text{MHz}
$$

这样的特定频率。

再后来就是：

```text
振荡器
  ↓
调制器
  ↓
功率放大器
  ↓
天线
```

也就是我们今天熟悉的现代 RF transmitter。

---

## 8. 和你最近学的 RF 联系起来

你可以把 spark-gap transmitter 看成一个**非常原始的 RF 发射机**：

```text
                    Spark-gap transmitter

       DC 高压
          │
          ▼
      ┌───────┐
      │ 电容 C │  ← 储存能量
      └───┬───┘
          │
          ▼
     ┌─────────┐
     │ Spark   │  ← 一个非常粗暴的开关
     │   Gap   │
     └────┬────┘
          │
          ▼
       LC 谐振
          │
          ▼
        天线
          │
          ▼
       📡 RF
          │
          ▼
      无线电波
```

所以你可以记住一句非常核心的话：

> **Spark-gap transmitter 的“spark-gap”不是为了产生无线电波本身，而是充当一个瞬间导通的高压开关，利用电容储能和 LC 谐振产生高频电流，再通过天线辐射出去。**

这也是为什么它在学习 **RF / 电磁学历史** 时很重要——它实际上把你最近问的 **Gauss's Law、Faraday's Law、Ampere's Law、天线、RF 振荡**这些东西串到了一起。
