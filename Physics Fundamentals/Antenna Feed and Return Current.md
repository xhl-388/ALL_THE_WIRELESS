# 天线馈电、回流与 PCB 地

**馈电（feed）**是把射频信号加到天线馈电端口；**回流（return current）**是电流返回射频信号源另一端所走的路径。回流不是“电流流进地里消失”，而是电路的一部分。

这里的“地”通常指 PCB 地平面、机壳或同轴线屏蔽层等 RF 参考导体，**不一定连接到大地**。在射频下，导线、地平面和机壳都有阻抗；“地”也不保证处处严格等电位。

## 馈电与回流：看完整的 RF 端口

同轴线有两个导体：中心芯线和屏蔽层。射频源在两者之间施加随时间变化的电压。中心芯线连接天线的一个馈电端，屏蔽层通常连接另一个 RF 参考端，例如 PCB 地平面。

```text
射频源的两个端子
  (+) ── 同轴中心芯线 ── 馈电点 ── 天线辐射臂
  (−) ── 同轴屏蔽层   ─────────── PCB 地平面 / 回流结构

                  辐射臂与地平面之间有 RF 电磁场
                  （不是一根金属线把它们短接）
```

射频电流快速交变，图中的电流方向每半个周期反转。天线辐射臂和地平面上会形成相应的电荷与表面电流分布；地平面上的电流通过馈线屏蔽层与信号源回路相连。

**不要把它想成电子从天线杆尖端穿过空气流进 PCB。**导体中的自由电子主要在局部来回振荡；天线导体之间的变化电场和电磁场参与电流连续性，并把能量辐射到空间。电流回路是电路与电磁场共同构成的，不一定是所有部分都由金属导线连成的直流闭环。

## 单极子与偶极子

### 单极子（monopole）

单极子有一根主要辐射臂，常见近似长度为四分之一波长。它通常需要地平面、机壳或其他反向电流结构作为 **counterpoise（配重/对置回流结构）**。因此，单极子系统不是“只有一根杆”，而是辐射臂、馈线和回流结构共同工作。

```text
          单极子辐射臂
                │
                │  表面 RF 电流随时间振荡
                │
        ────────●────────  PCB 地 / 金属地平面
                │           参与回流与辐射
         同轴中心接辐射臂
         同轴屏蔽接地平面
```

实际的电流分布会随地平面尺寸、馈线走向、频率和周围物体改变。经典无限大地平面模型可用“镜像天线”帮助分析，但真实 PCB 地平面是有限尺寸，不能简单当作理想无限地面。

### 偶极子（dipole）

偶极子有两根辐射臂，由馈电端口驱动。两臂上的 RF 电流通常方向相反；每一臂都不是“接地”，两臂共同形成天线。平衡偶极子可以不依赖大地平面，但附近的 PCB、机壳和馈线仍可能影响它。

## PCB 印刷天线需要“地”吗？

要看天线结构：

- **倒 F 天线（IFA/PIFA）及许多单极子式印刷天线**：常把 PCB 地平面作为天线系统的一部分，地平面尺寸会影响谐振、匹配和辐射方向。
- **印刷偶极子等平衡天线**：可以由两条辐射臂构成，不一定把 PCB 地当作另一条天线臂；但附近地平面仍可能改变性能。
- **净空区（keepout）**：天线走线周围往往要求不铺铜、不放器件或金属。要按天线厂商参考设计处理，不能随意把铜皮或金属件当作“地”补上。

## 散热片能不能当作“地”？

**有可能，但垂直摆放本身不会让散热片变成 RF 地。**要让散热片兼作回流面，通常需要它与天线参考地之间有合适的 RF 连接，并且尺寸、位置和连接结构符合设计。

直流万用表测得导通，不代表在 Wi-Fi 频率下连接阻抗一定足够低：连接长度、螺丝、氧化层、绝缘垫片和接缝都可能影响 RF 阻抗。没有接地的散热片也可能被天线场耦合，成为寄生导体并改变天线性能。

## PCB 上的电流会不会干扰器件？

会有这种可能，但通常首先表现为**电磁干扰或天线失谐**，而不是损坏器件。要区分：

- **设计内的回流电流**：在地平面、馈线屏蔽层和天线结构上分布，是天线正常工作的一部分。
- **意外耦合的寄生电流**：天线近场耦合到其他走线、金属件或电路环路，可能给敏感电路带来噪声，影响接收灵敏度或电路工作。

常见控制方式包括连续且合适的地平面、遵循天线净空要求、合理布置天线和敏感电路、控制馈线及回流路径，并按设计进行匹配与实测。PCB 地不是理想导体；接地过孔、缝隙、走线和共享阻抗都会影响 RF 电流分布。
